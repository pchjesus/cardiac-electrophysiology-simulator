# v1.12 Patch 2 — Guided navigation and native Timeline seek

**Scope:** user-approved A/A/A, small feature patch. **NOT v1.12 FINAL.** Physical-device acceptance and independent clinical validation are pending.

## Implemented changes

- Existing guided inspector is still opt-in. Closed dashboard remains the same height; original short clinical/nursing explanation and complete six-part teaching are preserved.
- `이전 단계` / `다음 단계` navigate exactly the existing five lessons (buttons disabled at the first/last stages). These are **study-only**, synchronized with the existing dropdown. **Never** change A/B, HR, playback, current view or Timeline.
- `Wiggers에서 보기` is a separate, deliberate user click. Calls the original `CardiacDashboard.setView('wiggers')` and preserves all time and playback values.
- `이 단계 관찰 시점으로 이동` is a separate deliberate click, preceded by a visible warning that it pauses and changes Timeline. The previously implemented read-only Mechanical/Wiggers midpoint is converted to the original `#timeSlider`'s 0.1%-step and one native `input` event is dispatched. The **original slider handler**, not the guide, owns pause, A/B clocks, ECG sweep and conduction redraw.
- No new timer, `requestAnimationFrame`, new physiology model, automated Wiggers switch, auto-seek from lesson navigation or patient data inference.

## Known scientific and user-visible boundaries

The selected study stage and actual playing phase are visibly distinct. Mid-stage seek is a **representative interior observation**, not the exact valve-opening/closing instant. Model RR later-segment `filling` is a simulator coordinate, not physiologically synonymous with clinical 'late-diastolic filling'; initial RR filling has flat model relative LV volume 0.88. Pressures/volumes are non-calibrated relative educational curves, not measured mmHg/mL/EF/CO. S1/S2 remain markers rather than recorded audio.
