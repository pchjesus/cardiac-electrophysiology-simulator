# Cardiac Electrophysiology Simulator — v1.11.1 Stabilization Release Notes

**Scope:** compact-first UI/UX, complete nursing explanation retention, responsive layout and regression hardening. No new physiological model. **v1.12 has not yet been implemented.**

## Rationale
At 1366×768, the v1.11 Electrical view scrolled to around 1,289px. The main issue was duplicated and lengthy information panels, not the physiological graphics. The accepted solution was an optional information hierarchy combined with a wide-desktop side-by-side ECG/control arrangement. Do not solve visual crowding by shrinking important plots or removing nursing content.

## Categories of change
| Category | v1.11.1 delivered behavior |
|---|---|
| Main workflow | Compact mode is the default. ECG Monitor, original HR 30–180 bpm, Timeline, Play/Pause/Reset, normal/brady/tachy presets, six measurement values, tabs, three current-status labels and concise physiological/nursing interpretation remain visible |
| Optional content | Full-information toggle opens original ECG-component, Current Phase and ECG Event detail; toggling back closes them. Six-part detailed nursing teaching remains independent |
| ECG selection | Selecting P/PR/QRS/ST/T reveals the original detailed component explanation automatically |
| Wide desktop | On screens >=1200px, compact controls and ECG share a horizontal row. The 65:35 visualization/explanation workspace is below the compact six-measurement strip |
| Mobile / tablet | Original stacked UI is retained; Wiggers retains its own scrollable wide SVG; no document-level horizontal overflow |
| Existing views | Electrical, Mechanical, Wiggers, Wiggers graph focus/split, category-based patch notes and practical guide retained |
| Scientific model | Unchanged ECG/A-B time and amplitude generation, Mechanical domain, Wiggers pressure/volume profile and educational model caveats |

## Risk management and verified behavior
The load-last dashboard presentation adapter still moves existing DOM nodes and existing event listeners, rather than cloning them. The new native details disclosures wrap the original dynamic text nodes and do not add independent state updates or timers. Opening full information must not alter HR, Timeline, A physiological time, B visualization time, playback, current visualization, Wiggers markers, graph focus or the Mechanical domain model.

The historical v1.11 browser test previously read the full nursing paragraph before the queued native details-toggle event had completed. Stabilization changes that test to **wait for the actual text condition**, retaining the full content assertion, rather than adding arbitrary sleeps or weakening the test.

Nine historical automated test suites plus new v1.11.1 real-index Chromium suite: **10 test steps and 449,265 explicit assertions** upon final successful execution. New v1.11.1 tests add 98 checks covering compact/full reduction, A/B-state identity, ECG selection, six full nursing sections, Wiggers, reset, user popups and 360/390/768/1024/1366/1440px viewport behavior. Screenshots from actual Chromium desktop compact/full, Wiggers and mobile are archived as workflow artifacts; this is **not** manual target-device visual approval.

## Scientific limits carried forward
The ECG denotes electrical events, not simultaneous mechanical contraction. Relative LA/LV/aorta pressures are not mmHg. LV volume is a normalized educational drawing, not LV mL, stroke volume, cardiac output or EF. S1/S2 are valve-event markers, not sound wave recordings. Bradycardia and tachycardia rate examples do not diagnose unstable patients. Mechanical/Wiggers exact valve tie rounding and high-HR QT/QTc teaching approximations remain existing model limitations.

## Physical device acceptance still pending
- Actual computer at 1366×768 / 1440×900: core content, legibility and ECG animation pace.
- Touch/mobile at 360 / 390px: density toggle, tap targets, no page-level horizontal scrolling, Wiggers internal scroll.
- Three views, Wiggers focus/split, Play/Pause/Reset, HR presets/manual, ECG-component detail selection and Timeline.
- Full medical/nursing narratives and model caveats, change-history and guide popups.
- Collect issues, reproduce and patch; do not label FINAL or clinically validated on CI alone.
