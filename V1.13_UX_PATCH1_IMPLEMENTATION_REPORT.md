## Bug and regression boundaries

- One existing Guided question panel/10 canonical choices/answers; DOM rehoming occurs in prior router, no clone. On Unit 1 the explicit Guide entry action retains native Ready-first Seek-once; tab/chapter navigation and read-only clinical view remain no-seek.
- A/B heart clocks, Play/Pause/Reset, timeline sweep and heart models not modified. Clinical patient ECG/HR/BP never touches simulator.
- A1 compact index uses one media-query change event and native details state, not an extra RAF or polling clock.
- E1 ECG/labs retain source-case availableFromPhase/time status. Symptoms and concerning BP never hidden in details; on <=999px only the optional evidence section collapses, the actual clinical question and key patient state stay visible.
- Clinical tab remains disabled outside internal v113Preview until **independent expert** has verified all fictional numbers, ECG interpretation, answer keys, rationales and refs and explicitly approved public release.
- Existing Clinical answer submission, confirm/restart, course manual completion, answer review/learning-return and actual Guide teaching stages preserve the prior state ownership.

## Follow-on content risks excluded from visual UI patch

Existing clinical distractors are overly easy and the static case ECG description does not teach full strip interpretation. Do not silently claim those are expert-approved. A separate clinical educator review should either add an appropriate, verified ECG specimen and plausible nursing-assessment distractors or restrict the first case's aims to patient status/urgency/report/reassessment. The frozen clinical scenario remains draft and public-gated.
