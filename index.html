모델의 가정·한계

교육용 모형은 실제 환자의 혈역학을 예측하지 않습니다.

세로 표시선은 생리학적 시간(A)을 따릅니다. 상단 ECG의 흐르는 화면은 별도의 시각화 시간(B)을 사용하므로 가로 위치가 정확히 같지는 않습니다. 압력 곡선과 판막 그림은 사건 경계를 약간 다르게 표시할 수 있습니다.

위거스 도표(Wiggers diagram)는 무엇인가요?

위거스 도표는 심장 한 번의 박동 동안 심전도·심장 압력·판막 개폐·심실 용적·심음이 어떻게 이어지는지 같은 시간축에 놓은 그림이에요.

왜 중요할까요? QRS파 뒤 심실이 수축하고, 압력이 변하면서 판막이 열려 혈액이 박출되는 흐름을 서로 연결할 수 있어요. 숫자를 외우기보다 원리를 이해하는 데 도움이 됩니다.

  1. 심전도: P파는 심방 탈분극, QRS파는 심실 탈분극, T파는 심실 재분극과 관련됩니다. 전기 변화와 실제 수축은 동시에 일어나지 않습니다.
  2. 압력: 좌심방·좌심실·대동맥의 압력 변화를 비교하고 어느 판막이 열리거나 닫히는지 살펴보세요.
  3. 용적: 등용적 단계에서는 거의 일정하고, 박출 때 감소하며 충만 때 증가하는 관계를 살펴보세요.
  4. 판막·심음: 승모판 닫힘(S1) → 대동맥판 열림 → 대동맥판 닫힘(S2) → 승모판 열림 순서를 관찰하세요. S1·S2는 실제 심음이 아니라 모형의 사건 표지입니다.

모형의 한계: 세로선은 생리학적 시간(A)을 따르며 상단 ECG 스크롤은 시각화 시간(B)으로 표시됩니다. 곡선은 교육용 상대값이고 실제 혈압·용적·박출률(EF)이나 환자 상태를 뜻하지 않습니다.

1. 처음 시작 · 자유 관찰과 단계 학습

v1.13 UX Patch 1: ① 시뮬레이터는 기존 ECG·Electrical·Mechanical·Wiggers와 원래 Play/Pause/Reset/Timeline을 유지합니다. ② 학습은 6단원 안내형·자유 탐색을 제공하며, 1단원에서 기존 심장주기 5단계·10문항을 그대로 사용합니다. PC에서는 단원 목록이 왼쪽에 보이고, 모바일에서는 '학습 단원 선택'을 열어 이동하세요. 단원 이동만으로 시뮬레이션 시간은 바뀌지 않습니다. ③ 임상 적용은 가상 사례 전문가 검토 전까지 일반 사용자에게 비활성화되어 있으며 ?v113Preview=1은 개발 검증 전용입니다.

자유 관찰에서는 재생(Play)·일시정지(Pause)·초기화(Reset), 심박수(HR, 분당 30~180회), 시간 막대(Timeline)를 그대로 조작합니다. ECG·현재 전기/기계 단계·간호 요약은 실시간으로 갱신됩니다. 타임라인 직접 조작은 일시정지와 위치 이동을 수행하며 모든 시각화 탭이 같은 모델 시계를 사용합니다.

5단계 학습을 열면 먼저 1. 기초 이해로 시작합니다. 심방 수축 → 등용적 수축 → 심실 박출 → 등용적 이완 → 모델 RR 후반 심실 충만을 탐색합니다. 이전/다음 또는 단계 선택은 사용자 명시적인 학습 행동으로서 자동 Pause + 해당 단계 대표 관찰 시점 Seek를 기존 Timeline으로 정확히 한 번 수행합니다. 상위 학습 탭 진입과 6단원 이동은 시간에 영향을 주지 않습니다. 단, Ready에서 '5단계 학습 시작'을 최초로 명시적으로 누르면 기존 Timeline으로 첫 대표 관찰점에 한 번 이동합니다.

읽는 설명과 실제 재생 상태는 다릅니다. 재생(Play)을 눌러 심장이 움직여도 선택한 학습 카드 문장은 사용자가 단계나 수준을 바꾸기 전까지 유지됩니다. 실시간 전기·기계·ECG 상태는 계속 갱신됩니다. 이 단계 다시 관찰은 같은 단계의 대표 시점으로 돌아가며 일시정지합니다. 위거스 도표(Wiggers) 전환은 사용자가 직접 보기 버튼을 누를 때만 이루어집니다.

읽는 깊이는 1. 기초 이해 → 2. 간호 연결 → 3. 추가학습 순으로 높일 수 있습니다. 단계나 학습 수준을 바꿔도 기존 문제의 답안은 유지됩니다. 이해도 확인을 펼쳐 기본·심화 총 10개 문항에 접근하고, 정답 확인 후 해설을 읽거나 해당 문제만 다시 풀 수 있습니다. 답안은 새로고침 시 초기화되며 환자 진단이나 자격 평가가 아닙니다.

자료 목록 보기를 누르면 긴 해설을 전부 펼치지 않고 전도 단계·ECG 사건·간호 원문의 주제 목록만 보여줍니다. 읽고 싶은 주제만 펼치고, 핵심 보기로 전환하면 다시 접습니다. ECG Monitor의 P/PR/QRS/ST/T는 해당 ECG 구성요소 설명을 직접 열어줍니다. 자료 원문과 상대 지표 한계는 보존됩니다. 화면의 ? 개념 또는 용어 알아보기를 누르면 뜻·학습의 중요성·관찰 방법·모형의 한계를 설명하는 팝업이 열립니다.

2. 전기전도 / 수축·판막 / 위거스 도표

심전도(ECG) 모니터는 항상 표시됩니다. 그림 보기에서 전기전도(Electrical)는 전기 신호 이동을, 수축·판막(Mechanical)은 판막과 혈류를, 위거스 도표(Wiggers)는 심전도·압력·용적의 시간적 관계를 보여줍니다. 탭 전환은 HR, 재생 상태와 A/B 시간 자체를 바꾸지 않습니다. 키보드 방향키·Home·End로도 시각화를 전환할 수 있습니다.

3. 위거스 도표(Wiggers diagram)

중앙의 위거스 도표(Wiggers)를 선택해 심전도(ECG), 좌심방·좌심실·대동맥의 상대 압력, 좌심실의 상대 용적, 판막 사건 마커 및 S1/S2 표시를 비교합니다. 패널 제목 옆 ?는 정의·중요성·읽는 방법을 설명하는 도움말입니다.

세로 표시선은 생리학적 시간(A)의 한 RR 주기를 나타냅니다. 위 심전도 모니터의 흐르는 그림은 별도의 시각화 시간(B)으로 표시되므로 두 화면의 가로 위치가 일치하지 않을 수 있습니다.

4. 정상·서맥·빈맥 학습

상단에서 정상 범위 분당 72회 / 서맥 분당 50회 / 빈맥 분당 120회 시나리오를 고른 뒤 시간 막대(Timeline)와 판막 사건을 비교하세요. 심박수(HR) 조절기를 직접 움직이면 직접 선택 상태로 돌아옵니다.

하단 자료 찾아보기 → 간호 원문을 열면 각 단계의 ECG→압력·판막→상대 용적→환자 사정 포인트를 읽을 수 있습니다. 실제 환자의 혈압, 박출량, 전부하 또는 병적 상태를 예측하지 않습니다. PC에서는 Wiggers 탭의 확대 보기로 그래프를 전체 너비로 볼 수 있고, 다시 분할 보기로 돌아올 수 있습니다.

5. 간호학적 활용과 주의사항

ECG 소견을 환자의 혈압, 맥박, 산소화, 의식, 증상, 관류 평가 및 심음 청진과 연결해서 학습하세요. P파/ QRS/ T파는 전기적 사건으로 기계적 수축과 정확히 같은 시각이 아닙니다.

서맥·빈맥 수치는 병적 상태를 확정하지 않습니다. 이 앱의 S1/S2는 소리가 아닌 사건 표시이며, 상대 압력은 mmHg가 아니고 상대 용적은 mL 또는 EF가 아닙니다. 고심박수 ECG 간격과 QTc에는 교육용 근사의 한계가 있습니다.
