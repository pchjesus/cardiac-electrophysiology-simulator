## Functional implementation

### P2 — original Guided rehost
- The existing `#guidedV112Toggle` / `#guidedV112Panel` are MOVED, never copied, to `#v113LearningGuideHost` whenever Learning is selected; the same original quiz question bank, listener objects, selections, answers, native seek and detail levels remain live.
- Historical Simulator-first Guide interaction remains available until entering Learning; afterwards the Inspector button becomes an explicit Learning navigation, and the original live Inspector remains readable on Simulator return.
- Merely switching top-level tabs never starts Guided, changes selected Guide stage, or dispatches native Timeline input. Explicit original Ready Guided Start and explicit prior/next/select preserve the historic seek behavior.
- The Guide's explicit 'Wiggers에서 보기' is the only cross-view shortcut selecting original Wiggers and going back to Simulator; it does not seek.

### P3 — six-unit learning
- New `course-v113.js`: immutable six-unit learning catalogue and user-facing anatomy/conduction/ECG/timing/mechanics/Wiggers/nursing concepts.
- Guided/free navigation, manual unit completion, selected chapter and Clinical-related learning return link are independent of original Guide and `heartState`. No new quiz or animation driver.
- Existing five mechanical stages and ten qualitative questions remain the sole guided lesson and quiz source. Guide is only accessible through the intentional original button, not auto-started from chapter browsing.
- An explicit simulator observation button opens original Electrical/Mechanical/Wiggers without changing A/B. Every core educational paragraph includes a model caution and nursing context.

### P4 — static fictitious clinical case + schema validator
- New `clinical-cases-v113.js`: one internally authored, fictional symptomatic bradycardia/low-pulse nursing assessment case; baseline vitals, separately authored ECG text (NOT live sinus waveform), lab pending/result timings, fixed reassessment, four education-focused choices with individual feedback, citation links, six-unit deep links.
- The immutable fixture is checked for schema, ID uniqueness, question order and correct option, choice-specific feedback, source and learning-unit links, lab value/null/status, sample-to-result timing and chronology.
- **Crucial: medical expert review has not occurred.** Scenario values, causal interpretation, ECG wording, all correct keys and teaching explanations are *review-pending educational draft*. It cannot be labelled expert-validated.

### P5 — independent Clinical Case player (QA-only until review)
- New `clinical-v113.js`: case catalogue/start, baseline observations, judgement/action/reassessment question flow, explicit submit and explanatory feedback, source links, 4-question dynamic results, wrong-answer learning jump / return, explicit two-step restart and exit.
- Session does NOT copy or mutate the original Guided/Quiz/simulator clock. Native Simulator Reset leaves clinical answers untouched; top-level tab transitions preserve submitted choices, current phase and reviewed outcome.
- Clinical tab is enabled at `?v113Preview=1` for integrated QA, but **disabled for ordinary public use until the independently reviewed first case changes to `status:'clinical-reviewed'` after actual approval**. Merely passing a case schema validator is not clinical signoff.
