# v1.12 — 5단계 심장 주기 교육 콘텐츠·문항 설계

> **표기 정확성 보완:** [V1.12_DESIGN_REFINEMENT.md](V1.12_DESIGN_REFINEMENT.md)를 함께 읽을 것. 이 문서의 ‘후반 심실 충만’은 **현재 모델 RR 주기의 후반에 표시되는 충만 구간**을 뜻하며, 일반 생리학의 ‘후기 이완기 충만’이나 ‘심방 수축에 의한 최종 충만’을 뜻하지 않는다. 실제 생리학과 시뮬레이터의 시점 경계를 혼동하지 말 것.

> **설계 자료, 코드 미구현 / 의료 교육용**. 기존 `wiggers-learning.js`의 5단계 `PHASES` 내용 및 `RATE` 주의문구를 1차 자료로 하고, OpenStax 심장주기와 StatPearls cardiac cycle의 일반 원리를 대조했다. 임상적 추론을 넘겨짚지 않으며 앱의 상대 수치를 실제 환자 수치처럼 표시하지 않는다.
>
> 학습 안내의 첫 단계는 모델 RR 증가 방향에 맞춰 **심방 수축**으로 시작하고, **후반 심실 충만**으로 마무리한다. 이는 5종 기계적 단계를 한 주기 안에서 순서대로 추적하려는 교육용 선택이다. 생리학적으로 심실 충만은 다시 다음 심방 수축까지 계속된다는 점을 안내해야 한다.

## 0. 과학적 근거와 표시 구분

- **[생리학적 원리]**: 일반적으로 확립된 전기-기계 지연, 압력 차·판막 운동, 심장 주기, 용적 흐름과 심음 관계. OpenStax 및 StatPearls에 근거.
- **[이 앱의 교육용 모형]**: 좌심계의 무차원 상대 압력·상대 좌심실 용적, HR별 경험적 경계, 심음 대표 마커, 5개 `stage`. **실측 mmHg / mL / EF / CO 아님**.
- **[간호학적 관찰 관점]**: 활력징후·ECG·맥박·심음·말초관류·호흡·의식·증상 등을 서로 연결해 이해하도록 하는 예시. 실제 환자의 진단·치료 결정 아님.
- **[알려진 한계]**: 심방-심실 기계적 지연과 좌우 심장 이벤트의 차이, 모델 Mechanical/Wiggers 경계 tie, 고HR QT/QTc 근사, filling의 중복 구간.

## 1. 실제 모델 경계 매핑 — 정확성이 최우선

| 단계 ID / 화면에 보일 한국어 | 시간 구간 (기존 코드 그대로) | Wiggers 모델 승모/대동맥판 | 상대 용적 | 대표 전기 사건 / 오해 주의 |
|---|---|---|---|---|
| `atrial_systole` / 심방 수축 | `[atrialStart, contractionStart)` | 승모판 열린 상태 / 대동맥판 닫힘 | 0.88 → 1.00 | P파는 심방 탈분극이며 **수축과 동일한 순간이 아님** |
| `isovolumetric_contraction` / 등용적 수축 | `[contractionStart, ejectionStart)` | 둘 다 닫힘 | 1.00 유지 | QRS 심실 탈분극 후 압력 증가. 승모판 폐쇄 = 좌심계 S1 대표 사건 |
| `ejection` / 심실 박출 | `[ejectionStart, ejectionEnd)` | 승모판 닫힘 / 대동맥판 열림 | 1.00 → 0.48 | 심실 수축에 따른 박출. T파는 후반에 겹칠 수 있으나 T파 끝 = 대동맥판 폐쇄 아님 |
| `isovolumetric_relaxation` / 등용적 이완 | `[ejectionEnd, relaxationEnd)` | 둘 다 닫힘 | 0.48 유지 | 대동맥판 폐쇄 = 좌심계 S2 대표 사건. T파와 기계적 이완은 단일 시점에서 일치하지 않음 |
| `filling` / 심실 충만(후반) | `[relaxationEnd, rr)` | 승모판 열림 / 대동맥판 닫힘 | 0.48 → 0.88 | 심실 압력이 심방보다 낮아지는 흐름. 다음 P파 전까지 이어짐 |

**충만에 관한 모델 예외 (교육 콘텐츠 MUST 표시):** `[0, atrialStart)`도 `stage=filling`이지만 현재 `wiggers-profile.js`의 상대 용적은 0.88로 **일정**하다. 실제 심실 충만이라는 생리학적 일반론과 ‘현재 도식의 초기 구간은 일정한 상대 용적으로 그려짐’이라는 모델 특성을 혼동하지 않는다. 가이드의 시점 이동은 후반 `[relaxationEnd, rr)`의 중간을 선택한다. HR 변화에 따른 단계 계산은 항상 동적 경계를 사용한다.

## 2. 단계별 학습 카드

### 1. 심방 수축 (atrial_systole)

- **학습 목표:** P파와 심방 수축의 관계를 시간적으로 구분하고, 방실판막이 열려 있을 때 이완기 말 충만이 보완됨을 설명한다.
- **ECG [생리학]:** P파는 심방의 전기적 탈분극. 심방근의 실제 수축은 그 이후 나타난다.
- **판막/압력 [생리학+모형]:** 좌심방→좌심실 압력 구배가 유지되는 모델에서 승모판은 열려 있고, 대동맥판은 닫혀 있다.
- **용적 [모형]:** 상대 LV 용적이 0.88에서 1.00으로 증가한다. 이는 실제 atrial kick의 기여 비율이나 EDV 실측값이 아니다.
- **간호 관찰:** ECG의 P-QRS 관계와 맥박의 규칙성, 환자의 증상·혈압을 함께 본다. **P파 존재가 기계적 심방 수축과 충분한 관류를 보증하지 않는다.**
- **주의 문구:** 전기-기계 지연, 심방 기능 장애·판막 질환은 임상적으로 변수가 많으나 이 모델은 재현하지 않는다.

### 2. 등용적 수축 (isovolumetric_contraction)

- **학습 목표:** QRS 이후 수축의 시작과 승모판 폐쇄/S1 모델 마커를 연결하고, ‘압력은 증가하면서 용적은 일정하다’는 뜻을 정확히 설명한다.
- **ECG [생리학]:** QRS는 심실 탈분극. 실제 장력 생성과 판막의 사건은 ECG 파형과 정확히 같은 시간에 시작되지 않는다.
- **판막/압력 [생리학+모형]:** 승모판이 닫히고 대동맥판은 아직 열리지 않아 좌심실 압력이 증가하되 박출 흐름은 없다.
- **용적 [모형]:** LV 상대 용적 1.00 유지. `등용적`은 압력이 아니라 **용적이 일정**함을 뜻한다.
- **간호 관찰:** S1을 수축 초기의 대표 사건과 연결한다. 실제 S1에는 승모판·삼첨판 관련 사건이 포함되고, 현재 앱은 좌심계 마커만 표시한다.
- **주의 문구:** 좌우 판막 폐쇄의 미세 시간차나 실제 심음 크기는 구현되어 있지 않다.

### 3. 심실 박출 (ejection)

- **학습 목표:** 대동맥판이 열리는 압력 조건을 이해하고 상대 LV 용적 감소와 T파의 시간 관계를 구분한다.
- **ECG [생리학]:** QRS 이후 시작된 기계적 수축이 지속된다. T파에 대응하는 심실 재분극은 박출 후반과 겹칠 수 있지만 박출의 특정 끝 시각을 직접 측정하지 않는다.
- **판막/압력 [생리학+모형]:** 좌심실 압력과 대동맥 쪽 조건에 의해 대동맥판이 열린 후 박출이 이루어진다. 승모판은 닫힌다.
- **용적 [모형]:** 상대 LV 용적이 1.00→0.48로 감소. 값의 차를 실제 일회박출량이나 EF로 환산하지 않는다.
- **간호 관찰:** 전기적 리듬만으로 실제 박출과 관류를 판정하지 않는다. 맥박·혈압·의식·말초관류·호흡을 함께 본다.
- **주의 문구:** 후부하·수축력·대동맥 탄성·실제 박출량은 별도로 모델링하지 않는다.

### 4. 등용적 이완 (isovolumetric_relaxation)

- **학습 목표:** 대동맥판 폐쇄/S2와 두 판막이 닫힌 상태에서의 압력 하강을 이해한다.
- **ECG [생리학]:** 심실 재분극(T파)과 기계적 이완에는 관련성이 있지만 정확히 한 점이 아니다.
- **판막/압력 [생리학+모형]:** 대동맥판 폐쇄 후 승모판이 열리기 전까지 두 판막이 닫혀 있고 LV 압력이 하강한다.
- **용적 [모형]:** 상대 LV 용적 0.48 유지.
- **간호 관찰:** S2를 주로 대동맥판·폐동맥판 폐쇄 사건과 연결해 이해한다. 실제 청진에서 분열·강도·잡음 등은 모델에 없으므로 임상 증상과 함께 사정하는 사고 연습으로만 활용한다.
- **주의 문구:** `S2`는 오디오가 아닌 좌심계 대동맥판 폐쇄 시점을 나타내는 마커다.

### 5. 심실 충만(후반) (filling)

- **학습 목표:** 좌심실 압력 하강 후 승모판이 열리고 충만이 재개되는 이유를 설명한다.
- **ECG [생리학]:** ECG 기저선은 전기 사건이 겉으로 뚜렷하지 않은 구간을 의미할 수 있지만, 기계적 혈류가 모두 정지한 것은 아니다.
- **판막/압력 [생리학+모형]:** 좌심실 압력이 좌심방 압력 이하가 되어 승모판이 열리는 모델 사건 이후, 좌심방→좌심실 흐름을 보인다. 대동맥판은 닫혀 있다.
- **용적 [모형]:** 후반 충만 구간에서 상대 LV 용적 0.48→0.88 증가. 다음 RR 처음 구간은 같은 `filling` stage지만 상대 용적이 0.88로 평탄하다는 구현 특성을 필수 표기.
- **간호 관찰:** 심박수뿐 아니라 혈압·호흡곤란·체액상태·증상·말초관류를 함께 파악하는 관점을 강조한다.
- **주의 문구:** 실제 충만량은 심실 순응도, 전부하, 정맥환류, 이완 상태 등에 따라 달라지며 여기서는 예측 불가.

## 3. 10개 질적 이해도 문항 (각 단계 2개)

문항은 학습용이며 **진단/치료 조언, 환자 수치 예측, EF 계산은 제외**한다. 오답 해설에도 모델 한계를 드러낸다.

| 단계 | 문항/선택지 | 정답 | 핵심 해설 |
|---|---|---|---|
| 심방 수축 Q1 | P파가 직접 의미하는 것은? A. 심방 탈분극 / B. 승모판 폐쇄 / C. 실제 심방 박출량 | **A** | P파는 전기적 사건. 실제 심방 수축은 후행 |
| 심방 수축 Q2 | 현 모델의 심방 수축 중 승모판 상태는? A. 닫힘 / B. 열림 / C. 반복 교대 | **B** | 이완기 말 추가 충만 중 AV 판막 열림 |
| 등용적 수축 Q1 | 등용적 수축 중 일어나는 것은? A. LV 압력 증가, 용적 일정 / B. LV 압력 일정, 용적 감소 / C. 대동맥판 열림 | **A** | 두 판막이 닫힌 상태에서 압력이 증가 |
| 등용적 수축 Q2 | 이 도식의 S1 대표 마커와 연결된 사건은? A. 승모판 폐쇄 / B. 대동맥판 폐쇄 / C. 승모판 개방 | **A** | 실제 S1에는 승모판·삼첨판 요소가 있으나 그림은 좌심계만 대표 |
| 박출 Q1 | 모델의 대동맥판이 열릴 때 상대 LV 용적의 방향은? A. 증가 / B. 감소 / C. 일정 | **B** | 박출 중 감소, 실제 SV/EF 계산 불가 |
| 박출 Q2 | T파가 끝나는 순간 대동맥판이 반드시 닫히는가? A. 그렇다 / B. 아니다 / C. HR 80일 때만 | **B** | ECG 재분극과 판막 사건은 서로 다른 과정 |
| 등용적 이완 Q1 | 두 판막이 닫힌 이완 단계에서 모델 변화는? A. 압력 하강·용적 일정 / B. 압력 증가·용적 증가 / C. 대동맥판 개방 | **A** | 대동맥판 폐쇄 이후 승모판 열림 전 |
| 등용적 이완 Q2 | 이 도식의 S2 대표 마커와 연결된 사건은? A. 승모판 폐쇄 / B. 대동맥판 폐쇄 / C. 심방 수축 | **B** | 실제 S2에는 대동맥판·폐동맥판 폐쇄가 관련 |
| 심실 충만 Q1 | 승모판이 열린 후 좌심실 용적은 모델의 후반 충만 구간에서? A. 증가 / B. 감소 / C. 변하지 않음 | **A** | 후반 충만은 증가하지만 주기 초반 `filling` 구간은 평탄하므로 모든 시점에 적용 금지 |
| 심실 충만 Q2 | 교육용 상대 LV 용적 0.88은 실제 무엇을 뜻하는가? A. EF 88% / B. 88 mL / C. 단위 없는 교육용 지표 | **C** | 실제 mL·EF·박출량 환산 금지 |

**정답 표시 원칙:** 답을 선택하기 전에는 정답 여부를 노출하지 않으며, 답 선택 후 왜 맞는지·다른 답이 왜 틀렸는지 짧은 피드백을 표시한다. 학습 점수는 임상 숙련도 인증처럼 제시하지 않는다. 답을 다시 선택하거나 단계를 이동해도 기존 A/B 상태는 보존한다.

## 4. 초급·심화 설명의 정확한 차이

| 항목 | 초급 (기본) | 심화 (선택) |
|---|---|---|
| 단계 정보 | 단계·ECG 사건·판막 상태·상대 용적 변화·간호 관찰 핵심 1~2문장 | 기존 `PHASES`의 electrical/hemo/volume/nursing/caution 전체 문장과 HR별 RATE 비교 |
| 시간 정보 | 전기적 사건이 수축에 선행한다는 관계 | 현재 HR에서 계산된 모델 RR 및 대표 시간 경계, 실제 환자 측정값이 아님을 표시 |
| 학습 질문 | 기본 개념 1문항 | 판막 사건/모델 한계 등 두 번째 문항을 추가 |
| 임상 | 활력징후·관류 함께 사정 | 심음·심박수·환자 증상 맥락에서 오해를 방지하는 심화 주의점 |

가이드를 닫아도 사용자가 독립적으로 열었던 기존 `심화 의학·간호 해설` disclosure는 그 상태를 유지. **간단히 보여주는 과정에서 오해를 유발하는 설명 삭제 금지.**

## 5. 의학·간호 검증 체크리스트

- 모든 문장에서 ECG 사건과 기계적 수축을 ‘동시’로 단언하지 않았는가?
- Mitral open/close, Aortic open/close 4개 경계와 S1/S2가 기존 모델 사건 ID와 대응하는가?
- 심실 충만의 2개 구간(0→atrialStart와 relaxationEnd→RR)에서 **서로 다른 용적 변화**를 정확히 설명하는가?
- 등용적 수축/이완에서 상대 용적 일정, 압력만 변한다는 설명이 맞는가?
- 상대 pressure/volume, HR 시나리오, QT/QTc 근사 등을 실제 환자 혈역학으로 예측하지 않는가?
- "상대 수치"와 "생리학적 원리"를 명확하게 분리 표시하는가?
- 환자 사정 예시는 간호학적 학습 관점이며 실제 치료 지시가 아님을 분명히 하는가?
- 화면 길이가 늘 때 내용을 삭제하지 않고 선택형 심화로 제공하는가?
- 실제 신체 심음 S1/S2의 우심계 기여를 빠뜨린 채, 앱 표시를 실제 심음 전체와 동일시하지 않는가?
