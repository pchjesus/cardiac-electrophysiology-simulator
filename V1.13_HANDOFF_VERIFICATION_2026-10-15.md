## 4. Open issues versus improvement candidates

### Confirmed outstanding release blockers (not code failures)

- Clinical data, fictional ECG wording, timing, lab/reference values, question keys/distractors and scope of nursing-student responses require **independent expert review**. No approval status change is authorized.
- Physical PC/Android UX, touch/keyboard/focus, screen reader and extended-session testing not signed off; app remains **NOT FINAL**.

### Source-confirmed localization/UX gaps (candidate improvements, not runtime bug reports)

- `index.html` and some `script.js`/`dashboard-v111.js` Ready-state strings still display **"Ready"** to learners.
- English-only accessible names remain, for example `index.html` SVG descriptions, `aria-label="Current conduction phase"`, `aria-label="Close user guide"`; `dashboard-v111.js` has `aria-label="Integrated cardiac simulation learning dashboard"` and similar descriptions.
- The built-in user guide still includes English-oriented headlines and instructions (e.g. "Electrical / Mechanical / Wiggers", "Wiggers Diagram", "Normal / Bradycardia / Tachycardia"). These are genuine Korean-first consistency gaps, **not** proof of broken operation.
- `tests/test_v113_integrated.py` directly exercises ECG and Wiggers popup behavior. A dedicated **seven-topic trigger/content/Escape/focus/mobile/answer-preservation matrix** would be stronger coverage before declaring popup QA complete.
- Six learning units have short core and nursing narratives. Enrichment should build progressive understanding without duplicating original 5-stage lessons or 10 questions.
- The first clinical case's distractors include easily dismissed options, and its descriptive ECG does not provide a verified tracing. Educational review should separate *patient-status judgement* from actual ECG rhythm interpretation before any public launch.

### Not confirmed as current defects

- No active JavaScript exception, clock desynchronization, duplicate RAF, state-loss, clinical leak or browser-layout regression has been reproduced as part of this handoff-only review. Previously green CI is evidence within its tested scope; the above candidates must not be mislabeled as reproduced bugs.
- Actual manual hardware testing has **not** been performed in this review.
