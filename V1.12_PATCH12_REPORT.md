## Scope
User-approved B-plan follow-through from Patch 9: P10 correct ECG label and Ready-state interpretation, P11 simplify initial learning and use existing native Timeline for first-stage observation, P12 improve text legibility, mobile ECG component accessibility and documentation consistency. v1.12 is an educational model and **NOT FINAL**.

## Conserved sources / clocks
- Preserved physiological A and visualization B time ownership, original waveform and sweep sampler, canonical heart rate/ECG interval engine, Mechanical/Wiggers profile, six clinical source sections, all five stage observations and ten original qualitative questions and answer explanations.
- No new timer, cloned Canvas/SVG, API, patient parameter, disease-specific or clinical prediction model.

## UX outcomes
- First reading is one-sentence student summary and Previous/Next. Original manual Wiggers, level dropdown, manual re-observe and model details live in optional native disclosure; nursing observations and source bank remain accessible through progression.
- Guided educational body grows to about 15–16px; labels/headings follow hierarchy. At mobile widths five ECG buttons wrap into a discoverable grid, without sideways button-list scroll.
- README/SPEC/START_HERE current status updated; superseded A/A/A or unimplemented references marked historical, with active B/B/B/B current handoff.

## Test gates and known limitations
- New tests: P10 30/80/180 bpm past-only label and Ready/Seek/Reset, P11 one-click guided first-stage/native A/B, P12 reading size, six-seven viewport widths, keyboard disclosure, content/question integrity. Existing earlier suites remain. Actual CI results must be linked at completion and not presumed.
- CSS viewport width ~680px approximates available CSS width after 200% desktop zoom, but does not prove true browser zoom / assistive tech compatibility; real device and actual zoom checks remain for user acceptance.
- Manual checklist: physical Windows screen at 1366x768 / 150-200% zoom, mobile 360–390px, start/play/pause/seek/HR changes, electrical vs mechanical vs Wiggers, quizzes and source disclosures, fast live text, focus + scroll, labels after seek. Final release is explicitly blocked until user confirms.
