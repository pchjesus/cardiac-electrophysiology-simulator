# Cardiac Lab UX Reset v2 — 설계·통합 계약 (사용자 검수 전)

## 목표
기존 UI의 카드 누적을 중단하고 **관찰 → 조작 → 원인/결과 해석 → 학습 적용** 순서로 재설계한다. 레퍼런스의 원리만 참고하고 RAAS 화면을 복제하지 않는다.

## 화면 구조
1. **진입**: 학습 목적과 세 단계 안내를 간단히 제시한다.
2. **시뮬레이터**: 상단 재생/일시정지/초기화·Timeline·HR·학습 시나리오 → 데스크톱에서 ECG·전기/기계/Wiggers 관찰·동기화된 생리학/간호 해설을 같은 가로 영역에 배치 → 측정값/심화 자료. 모바일에서는 정보 손실 없이 위에서 아래로 같은 순서.
3. **학습**: 기존 6단원과 5단계 Guided, 기존 10문항·답안·세션을 보존한다.
4. **임상 적용**: 기존 가상 사례/근거/QA 보호를 유지한다. `?v113Preview=1`은 개발 검수 전용이며 콘텐츠 공개 승인이 아니다.

## 상태·데이터·범위
- A/B 시간, 단일 requestAnimationFrame, 시각화 전환, HR, Timeline, 모든 원본 DOM ID와 이벤트 리스너는 **변경하지 않는다**.
- 기존 `dashboard-v111.js`, `main-tabs-v113.js`, 학습/임상 콘텐츠를 그대로 사용한다. 새 UI는 **원본 DOM을 복제하지 않는 스타일·의미적 안내 레이어**다.
- 모션은 기본적으로 상태 반응형 색·위치 전환만 허용한다. 움직임이 심장 모델의 시간처럼 보이지 않도록 독립 반복 애니메이션은 두지 않는다. reduced-motion을 존중한다.
- 압력/용적은 상대 교육 지표이며 실측/임상 예측이 아니라는 원본 고지를 유지한다.

## 위험·검수
- 기존 CSS에서 강한 선택자와 미디어쿼리가 누적되어 **새 레이아웃의 specificity 충돌**이 가장 큰 위험이다. 별도 `cardiac-lab-v2.css`를 마지막에 적용하고 데스크톱/모바일 너비별 직접 렌더링을 검토한다.
- `[hidden]`, 모달 포커스, 탭 이동 일시정지, Wiggers 확대, 자료목록 모드와 Guided 세션은 원본 구현에 맡긴다.
- 재생·정지·초기화·seek·HR 변화, 세 시각화 전환, A/B 상태 보존, 학습 답안·임상 비공개, 모바일 320/360/390/768/1366, 접근성·reduced-motion·콘솔 오류 검증이 필요하다.
- **이 문서는 디자인/구현 초안이며 완료 또는 최종 사용자 검수를 주장하지 않는다.**
- 브랜치/PR 단계의 미리보기만 제공한다. 사용자 승인 전 main 병합 및 운영 배포 금지.

## 도구·참고
Atlas 도구 및 스킬은 현 세션에 검색된 연결 도구 목록에서 발견되지 않아 직접 사용하지 않았다. 프로젝트의 교육 UI 표준 v1.1을 기준으로 설계했다.
