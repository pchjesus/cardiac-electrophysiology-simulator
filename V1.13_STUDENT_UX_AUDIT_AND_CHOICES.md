3. Clinical (clinical-v113.js): patient context, 2-column vitals, ECG, labs, question and answer display vertically. Repetition of the patient chart per phase and review cards makes the primary decision harder to find on mobile. Clinical is available only via QA preview because the fictional first case is NOT expert-reviewed.
4. Colors/borders (style.css): body text generally 16px / 1.62 line-height; secondary 13–15px. Numerous nested blue-bordered cards. Interactive outline #adc8d8 on #f5fafc is about 1.66:1 — below 3:1 WCAG 2.2 AA non-text contrast target for essential control boundaries.
5. Actual source confirms native physiological A / visualization B in original script.js, original Guided questions, Mechanical/Wiggers all remain isolated from the new course and clinical state. Any redesign must retain these invariants.

## User decisions — recommend one per category before broader redesign

### A. Screen layout / size

**A1 (recommended): adaptive focused learning** — PC flexible 220–250px course index + readable article ~650–800px; tablet one-column; mobile a compact chapter dropdown/collapsible index followed immediately by current material. Show the original Guided learning inside Unit 1, never clone it. Good balanced discoverability, but extra responsive logic and focus tests.

**A2: textbook/workbook** — 700–820px centered one-column article; chapters in a collapsible table of contents + previous/next. Best linear readability but slower to jump between topics.

**A3: analytic dashboard** — chapter index + reading + live visual summary simultaneously. Advanced overview, but dense and high risk to original Canvas/hidden-screen layout.

### B. Colors

**B1 (recommended): calm medical blue + small teal** — navy #183B56 headings, blue #246A92 primary actions, teal #176F65 for learning progress, warm amber only for genuine model cautions, pale #F7F9FB reading backdrop. Colors never convey right/wrong without labels.

**B2: minimal neutral textbook** — graphite #273444, slate #4C6575, warm #FAFAF7 backgrounds. Least visual noise but weaker role distinction.

**B3: dark monitor theme** — charcoal #152936 / bright text and cyan accent. Familiar ECG mood but more tiring for long academic reading; best optional later, not default.

All variants require WCAG 2.2 AA text >=4.5:1 (large >=3:1) and essential UI boundary >=3:1 at actual rendered state, keyboard focus and tested color vision accessibility.

### C. Cards and borders

**C1 (recommended): one-level soft cards** — clear outline around a whole unit/case; separate internal sections by white space and simple dividers, not border-within-border. Retain distinct borders on interactive answer choices.

**C2: categorized notebook cards** — independent boxes for core physiology, nursing meaning, caution, labs and quiz. Structured but potentially visually noisy.

**C3: typographic/divider-only reading** — minimal borders, strong heading hierarchy. Calm for text, less helpful for rapid patient data comparison.

### D. Learning content order

**D1 (recommended): novice-first** — unit goal → one-sentence mechanism → short explanation → nursing meaning → explicit simulator observation → original five-stage Guide/ten-question quiz when applicable → optional full existing scientific source and model limitations. Safety-critical caveats always visible near claims. Chapter navigation itself never runs Guide or Timeline.

**D2: reference-first** — concept and complete scientific detail before actions/quiz. Strong for repeat learners, verbose for novices.

**D3: visualize-first** — linked static illustration or step timeline before text. Potentially memorable but entails new authored visual source, accuracy/maintenance and A/B ambiguity risk.

### E. Clinical case layout

**E1 (recommended): patient snapshot + one current decision** — readable critical symptoms, HR/BP, timestamp near the question, optionally expandable *noncritical* history/ECG/labs in one phase-aware area. Never hide hypotension, new dizziness or other safety-critical signs. Question → direct submit → feedback → next. Preserve static observation availability and user case state.

**E2: full patient chart vertical** — current display with better spacing, phase anchors and a “return to patient data” shortcut. Minimal structural risk but mobile scrolling remains longer.

**E3: EMR-style multi-pane** — chart in one pane, decisions another. Rich realism, more complex/mobile-heavy and not recommended without new scope.

### F. Reading density

**F1 (recommended): balanced** — 16px main text / ~1.6 line-height; 14px secondary with sufficient contrast; 44–48px mobile controls; PC article line length kept comfortably readable.

**F2: spacious** — 17–18px body / ~1.65, increased vertical spacing. Better for smaller displays and accessibility, at the cost of more scrolling.

**F3: compact** — 14–15px body for PC quick-reference users. Not recommended as mobile default.

**Recommended selection:** A1 + B1 + C1 + D1 + E1 + F1. Any individual combination is acceptable. These choices are NOT implemented until approved.

## Clinical sources: design-level audit, not licensed clinical signoff

- 2025 AHA Adult Bradycardia With a Pulse Algorithm: HR typically <50/min in context; cardiopulmonary compromise includes hypotension, acute altered mental status, shock, ischemic chest discomfort, acute heart failure; assessment/support and evaluation of underlying causes. The proposed fictional HR42/BP86/54 with dizziness is educationally consistent with urgent assessment/report context, but this does **not** establish any independent clinical diagnosis or qualify a particular patient's management.
- Sinus education simulator HR<60 is a teaching rate category, not identical to the AHA algorithm's usual <50 bradyarrhythmia trigger. Fictional ECG text currently deliberately disclaims independent rhythm verification.
- MedlinePlus: lab reference intervals vary by laboratory and normal-range values cannot guarantee health. Fictional K 4.1 mmol/L does not establish cause or exclude risk; pending glucose is not zero or normal.
- Missing approval: independent clinician/nursing educator verification of vignette, all numbers, exact ECG wording, question keys/options, escalation scope, sources and final educational value. Retain the QA-only Clinical gate.
