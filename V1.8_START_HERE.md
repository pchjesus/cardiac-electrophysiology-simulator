# V1.8 START HERE

## Baseline

Start from **Cardiac Electrophysiology Simulator v1.7 FINAL**.

v1.7 completed:
- ECG measurements
- ECG event synchronization
- explicit conduction-path animation
- interactive ECG explanations
- unified simulation state feedback
- Normal / Bradycardia / Tachycardia educational rate scenarios

## First Goal

Do not begin by adding UI features. First inspect the v1.7 code and design the **Physiological ECG Model**.

### Required Architecture

Separate:
- **Physiological / Measurement Time (A)**
- **Visualization Time (B)**

Use one central model/state flow. Do not create competing timers or animation loops.

### Physiological Scope

Plan coherent relationships among:
- HR
- RR
- PR
- QRS
- QT
- QTc
- cardiac cycle length

The current v1.7 timing is intentionally simplified and must not be assumed to be physiologically exact.

## Regression Priority

Preserve:
- ECG waveform presentation
- ECG measurements/UI
- conduction animation
- Current Phase
- ECG Event
- Explanation
- Timeline
- Play/Pause/Reset
- heart-rate control and scenario UI
- responsive behavior

## Later Extension

The v1.8 timing architecture should be extensible to **Cardiac Cycle & Hemodynamics**:
- valve opening/closing
- chamber filling
- ventricular ejection
- blood-flow visualization

Then continue to 12-lead ECG, ECG interpretation, and case/quiz learning.

## Workflow

1. Inspect v1.7 code.
2. Identify current timing/state dependencies.
3. Design the physiological timing model.
4. Review regression risks.
5. Implement small patches.
6. Test all playback/timeline boundaries.
7. Update documentation after confirmation.
8. Archive the confirmed build.
